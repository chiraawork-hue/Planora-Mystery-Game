# Planora: Mystery Case

Game investigasi misteri berbasis web untuk kasus fiksi **Kematian di RSJ Asoka**.

## Fitur versi 0.2
- Antarmuka baru bergaya berkas investigasi: kertas arsip, tinta gelap, aksen merah, dan tipografi editorial.
- Lima berkas bukti yang harus dianalisis secara berurutan: laporan forensik, log akses elektronik, surat utang/catatan korban, denah jalur servis, dan transkrip wawancara.
- Setiap berkas memuat dokumen detail dan pertanyaan deduksi. Jawaban yang benar membuka tahap berikutnya; jawaban salah bisa dicoba lagi.
- Lima dossier tersangka berisi alibi, akses, motif, dan kaitan bukti.
- Buku catatan temuan terverifikasi, kronologi kejadian, dan laporan akhir yang memeriksa apakah teori pemain konsisten dengan bukti.
- Tampilan responsif untuk desktop dan ponsel.

## Menjalankan
Buka `index.html` di browser. Tidak membutuhkan build tools atau dependensi JavaScript. Google Fonts digunakan untuk tipografi; jika tidak tersedia, browser akan memakai font cadangan.

## Catatan
Semua nama, kasus, isi dokumen, dan kejadian adalah fiksi untuk permainan. Dokumen dibuat sebagai artefak HTML, bukan laporan forensik nyata. Foto korban dan bukti nyata tidak digunakan. Progres permainan saat ini hanya tersimpan selama halaman masih terbuka dan akan hilang saat dimuat ulang.

## Ide pengembangan berikutnya
- Tambahkan interogasi bercabang dan bukti foto yang benar-benar spesifik untuk setiap lokasi.
- Simpan progres pemain lintas sesi.
- Tambahkan sistem petunjuk bertingkat agar pemain bisa meminta bantuan tanpa langsung diberi jawaban.
