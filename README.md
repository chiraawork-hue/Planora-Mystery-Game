# Planora: Mystery Case

Game investigasi misteri berbasis web untuk kasus pertama: **Rahasia RSJ Asoka**.

## Fitur prototipe
- Arsip lima tersangka dengan profil, alibi sementara, motif/pertanyaan, dan keterkaitan.
- Galeri foto barang bukti yang bisa dibuka dan diperiksa.
- Catatan detektif dengan checklist bukti yang sudah diteliti.
- Kronologi kasus dan formulir laporan akhir.
- Tampilan responsif untuk desktop dan ponsel.

## Menjalankan
Buka `index.html` di browser. Tidak membutuhkan build tools atau dependensi JavaScript.

## Catatan
Foto pada versi awal ini merupakan gambar ilustratif dari Unsplash, bukan foto forensik asli. Narasi detail yang belum ditetapkan ditulis sebagai hal yang perlu diverifikasi. Formulir kesimpulan saat ini hanya prototipe dan belum memvalidasi jawaban kanonis pelaku.

## Pengembangan berikutnya
- Ganti foto ilustrasi dengan foto karakter dan bukti yang disetujui untuk cerita.
- Tambahkan dialog/interogasi dan sistem petunjuk yang saling terhubung.
- Implementasikan jawaban akhir kanonis berdasarkan naskah kasus.
- Simpan progres pemain lintas sesi.
